# Kharcha Tracker — Daksh Ki Pehli App 💰 (v2)

Roz ke kharche aur aamdani ka pura hisaab — login (PIN) ke saath, bilkul free, data sirf tumhare phone me.

**Live:** https://beingdaksh.github.io/kharcha-tracker/
**APK:** Releases me `apk-latest` → `kharcha-tracker.apk` (har update par apne aap banta hai)

## v2 me kya hai
- 🔐 Pehle login page — naam + PIN lock (data is phone me hi rehta hai)
- 🎨 Minimalist white / blue / red theme + dark mode (Settings)
- ☰ Hamburger menu: Dashboard, Weekly, Monthly, Yearly, Budgets, Settings
- 📅 Week / Month / Year ke alag views — pichhle periods bhi browse karo (‹ ›)
- 📊 Comparison: is period vs pichhla period (kitna zyada/kam %)
- 🎯 Mahine ka budget + category budgets, progress bar ke saath
- 🔔 Budget reminders (80% / pura hone par) + roz kharcha likhne ka reminder
- 💸💰 Kharcha + Aamdani dono, accounts (Cash / UPI / Bank / Card)
- 🔁 Recurring entries — salary, rent, EMI har mahine apne aap
- 🗂️ Apni categories banao, entries search/edit/delete karo
- 📈 Pie chart (category) + 6-mahine ka bar chart
- 💾 CSV export (Excel ke liye) + JSON backup
- 📴 Offline chalti hai, phone me app ki tarah install hoti hai

## Kaise bani
Ek hi `index.html` file (HTML + CSS + JavaScript) — koi library nahi. GitHub Pages par host hai, Capacitor + GitHub Actions se APK banta hai. Kul kharcha: ₹0.
