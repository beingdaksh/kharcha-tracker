# Kharcha Tracker — Daksh Ki Pehli App 💰

Roz ke kharche likho, aaj / 7 din / mahine ka total apne aap banta hai. Mahine ka budget set karo to bar dikhayega kitna kharch ho gaya. Saara data tumhare phone me hi save rehta hai (internet ki zaroorat nahi).

## Isme kya-kya hai
- Amount + category (Khana, Travel, Recharge, Shopping, Petrol, Bills, Entertainment, Aur) + note ke saath kharcha add
- Aaj, pichhle 7 din aur is mahine ke totals
- Category ke hisaab se is mahine ka kharcha
- Mahine ka budget + progress bar (80% par peela, 100% par laal)
- Galat entry ek tap me delete
- Offline chalti hai, phone me app ki tarah install hoti hai

## Phone se live karne ke steps (5 minute)
1. Browser me **github.com** par login karo (account nahi hai to free signup).
2. Naya repository banao: naam `kharcha-tracker`, Public.
3. Is folder ki saari files repo me upload karo ("uploading an existing file").
4. Repo ki **Settings → Pages** → Source: **main branch** → Save.
5. 1–2 minute me link taiyaar: `https://tumhara-username.github.io/kharcha-tracker/`
6. Link ko Chrome me kholo → **⋮ menu → "Add to Home screen" → Install**. Ho gaya — app tumhare phone me!
